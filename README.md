# 份子钱 · 微信云开发版

微信原生小程序、云函数和云数据库实现的长期人情往来账本。

## 运行

1. 微信开发者工具直接打开本目录；项目当前绑定云环境 `cloud1-d0gvdcxti865285c8`。
2. 创建 `users`、`contacts`、`gift_records`、`feedback` 四个集合，权限设为仅云函数可读写。
3. 右键 `cloudfunctions/api`，选择“上传并部署：云端安装依赖”。
4. 编译，勾选协议并登录。

新环境的部署、权限和索引检查详见 `CLOUD_ENV_SETUP.md`。

建议建立复合索引：`contacts(_openid, deletedAt, nameInitial, name)`、`gift_records(_openid, deletedAt, eventDate desc)`、`gift_records(_openid, contactId, deletedAt, eventDate desc)`。

金额统一以整数分保存，身份只取云函数 OPENID。支付、OCR、对象存储和 xlsx 导出需配置真实商户与云服务密钥后接入。

高级账本当前支持书架分类、服务端额度校验、账本详情、批量手工入账和礼簿照片上传。商品为 ¥9.9/1 本和 ¥19.9/5 本；正式付款与 OCR 不做前端模拟，必须配置微信支付 API v3 和腾讯云 OCR 后启用。

每位新用户自动获得 1 本免费体验账本；历史用户首次使用新版接口时也会补发一次。免费体验账本最多上传 20 张照片。批量手工处理不限制账本累计人数，单次最多提交 200 条，可重复分批导入；事件、日期和收支方向统一继承账本设置。

## 界面皮肤

“我的 → 界面皮肤”支持三套本地主题：丹青（默认）、暖棕、喜庆。选择结果保存在微信本地存储 `uiTheme`，只改变界面颜色与视觉层次，不读取或修改云端账本数据。切换后主页、记一笔和我的页面会同步更新主题。
